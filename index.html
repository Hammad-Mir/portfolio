IntelliMaint — Agentic Hybrid-Search RAG

Agentic RAG
Lead engineer GraphicWeave · 2025–26

A production-oriented async "Agentic RAG" microservice powering an equipment-maintenance assistant — technicians chat with an AI that answers repair and troubleshooting questions grounded in ingested manuals, with device- and document-type-aware retrieval and per-session document attachments. Shipped over 61 commits with feature branches, PRs, CI, and Docker Compose.

  • Hybrid retrieval: BM25 keyword + semantic search fused via Reciprocal Rank Fusion, then a custom content-aware reranker returning chunks from the dominant document — not naive top-k.

Behavioural Biometric Authentication (Keystroke Dynamics)

Time-Series ML
Computational Researcher · led R&D Peratech Holdco · Durham, UK · 2024–25

Led R&D on a behavioural biometric system that authenticates a user from how they type — from high-frequency, force-sensing keyboard data (144-channel pressure at 100 Hz), not passwords. A hard one-class problem: accept the genuine user, reject unseen impostors.

  • Designed a dual-pipeline architecture: a C# interface for real-time acquisition (100 Hz polling, synchronized keystroke + 144-channel pressure logging) and a Python ML pipeline for preprocessing, feature engineering, and representation learning.
  • Achieved 76% accuracy on the operationally realistic one-class task (genuine user vs. unseen impostors), with the closed-set binary task fully separable.
  • Engineered end-to-end pipelines for high-dimensional time-series, reducing storage 100× and improving throughput 40%; ran user studies capturing 2,500+ samples.
